# 首都医科大学EXCEL课表生成工具V3.1 👋

## 一键导出（浏览器插件版，v3.1新增）

### 第一步：安装浏览器插件（目前仅支持基于Chromium内核的浏览器，例如Chrome、Edge、Opera）
<img width="1892" height="150" alt="image" src="https://github.com/user-attachments/assets/464c6896-7c96-4d6e-8998-f3a1266a45a5" />

0. [下载扩展包](https://github.com/ccmu-schedule/extension/releases/latest) `.zip` 文件
1. 打开浏览器扩展程序界面（可以通过在地址栏输入`chrome://extensions/`，或`edge://extensions/，或`opera://extensions/`，也可以从“设置”中进入）
2. 开启“开发者模式”
3. 点击“加载未打包的扩展程序”
4. 选择解压缩后的对应文件



### 第二步：登陆教务系统，打开教务系统课表页，并选择对应的“学年学期”
